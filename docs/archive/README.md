# آرشیو اسناد

هر چیزی که در این پوشه است **منسوخ یا جایگزین‌شده** است، اما عمداً نگه داشته شده تا اطلاعات فنی‌اش گم نشود. هیچ‌کدام منبع رسمی نیستند؛ منبع رسمی هر موضوع در جدول پایین آمده است.

| فایل | چه بود | چرا آرشیو شد | جایگزین |
|---|---|---|---|
| `TECHNICAL-BRIEF.md` | بریف فنی ۱۸ بخشی (نسخهٔ سند ۱.۱۱.۱۷۱) | محتوایش به `docs/ARCHITECTURE.md` و `docs/DEVELOPMENT.md` منتقل شد | `docs/ARCHITECTURE.md` |
| `ARCHITECTURE-MAP.md` | ماتریس «خانواده → فایل CSS» + نقاط تداخل + اولویت باگ | ماتریس و تله‌ها در ARCHITECTURE ادغام شد؛ فهرست اولویت باگ منسوخ بود | `docs/ARCHITECTURE.md` |
| `WIDGETS-REFERENCE.md` | مرجع کوتاه خانواده‌ها و مکانیزم‌ها | با `docs/WIDGETS.md` هم‌پوشانی داشت و شمارش‌هایش قدیمی شده بود | `docs/WIDGETS.md` |
| `WIDGET-GUIDE.md` | قرارداد markup دقیق + فهرست کنترل‌های ویجت‌های محصول/آرشیو/سبد/تسویه | برای کاتالوگ جایگزین شد، اما markup دقیق و data-attributeهای JS هنوز مرجع ارزشمندی‌اند | `docs/WIDGETS.md` (کاتالوگ) · این فایل (قرارداد markup) |
| `release-notes/RELEASE-NOTES-*.md` | ۷۶ یادداشت بلند فارسی هر نسخه | محتوای هر نسخه در `CHANGELOG.md` هست؛ این‌ها نسخهٔ کامل و روایت‌محورند | `CHANGELOG.md` |

## این فایل‌ها هنوز به چه کار می‌آیند

- **`WIDGET-GUIDE.md`** — تنها جایی که markup دقیق هر ویجت و data-attributeهای قراردادی JS نوشته شده است. اگر ویجتی را از صفر بازنویسی می‌کنید، اول این را بخوانید.
- **`release-notes/`** — هر یادداشت دلیل طراحی و اندازه‌گیری همان نسخه را دارد. `CHANGELOG.md` خلاصه است؛ اگر می‌خواهید بدانید «چرا» یک تغییر انجام شد، اینجا را بگردید.
- **`TECHNICAL-BRIEF.md`** — جدول‌های اندازه‌گیری قدیمی (نسخهٔ ۱.۱۱.۱۷۱). اعداد به‌روز در `docs/PERFORMANCE.md` است.

## قاعده

فایل تازه به این پوشه اضافه نمی‌شود مگر اینکه جایگزین شده باشد. اگر سندی منسوخ شد، اینجا منتقلش کنید و یک ردیف به جدول بالا اضافه کنید.
