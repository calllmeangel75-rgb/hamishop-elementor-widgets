# نسخهٔ آزمایشی ۱.۱۱.۲۵۸ — فاکتور حساب مشتری

فقط برای محیط تمرینی ایزوله؛ نه سایت اصلی یا عرضهٔ تجاری. از محیط آزمایشی پشتیبان بگیرید.

در فاکتور مشتری و خلاصهٔ حساب، مجموع سفارش به جای مبلغ پرداخت‌شده نام‌گذاری می‌شود. برای سفارش مبلغ‌دار با روش اصلی ووکامرس «پرداخت هنگام دریافت»، به جای ادعای پرداخت‌شدن وضعیت سفارش نمایش داده می‌شود. این فقط اصلاح نمایش است و وضعیت، پرداخت و داده‌های سفارش را تغییر نمی‌دهد؛ حتی سفارش تکمیل‌شدهٔ پرداخت هنگام دریافت نیز به‌طور خودکار تأیید دریافت وجه نیست.

پس از نصب، همان فاکتور قبلی را بازآزمایی کنید؛ سفارش جدید لازم نیست. سایر درگاه‌های آفلاین، بازپرداخت و آزمون مالی به بررسی جداگانه نیاز دارند.
