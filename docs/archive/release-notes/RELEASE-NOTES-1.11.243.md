# یادداشت‌های انتشار نگارش 1.11.243 (Release Notes v1.11.243)

> **موضوع:** رفع سرریز افقی صفحهٔ مقاله در موبایل — علت پیدا شد و با اندازه‌گیری روی صفحهٔ زنده تأیید شد — به‌همراه دو مورد باقی‌مانده از بازبینی.

## ۱. صفحهٔ مقاله در موبایل افقی اسکرول می‌شد (+۵۲px)

**اندازه‌گیری روی `gilaclick.ir/pictorial-carpet-weaving-beginner-guide/` در عرض ۳۹۰px:**

```
document scrollWidth : 442   (viewport 390)   ← ۵۲px سرریز
```

برای پیدا کردن مقصر، اجزای ویجت را یکی‌یکی حذف کردم و هر بار اندازه گرفتم:

```
baseline          : 390 / 442   ← سرریز
hide dock         : 390 / 442   ← ربطی به نوار پایین نداشت
hide dock + pn    : 390 / 390   ← مقصر: ناوبری قبلی/بعدی
hide whole widget : 390 / 390
```

**علت:**

```
.hsw-pp__pn  →  عرض ظرف 342px، ولی ستون گرید 492px
                grid-template-columns: 1fr
```

یک ترک `1fr` حداقلِ خودکار دارد و زیر عرض محتوایش نمی‌رود. عنوان بلند مقالهٔ بعدی، ستون را به ۴۹۲px در یک ظرف ۳۴۲px کشید و کل صفحه را افقی کرد.

**رفع:**

```css
.hsw-pp__pn     { grid-template-columns: minmax(0, 1fr); }
.hsw-pp__pnitem { min-width: 0; }
```

و همان الگو برای نسخهٔ دسکتاپ (`minmax(0, 1fr) minmax(0, 1fr)`) و `.hsw-pp__relgrid` (مقالات مرتبط — همان ساختار با عنوان).

**تأیید با فایل CSS ساخته‌شده، شش عرض:**

```
  320  قبل 442 → بعد 338   (۱۸px باقی: .screen-reader-text قالب، نه ما)
  360  قبل 442 → بعد 360   ✓
  390  قبل 442 → بعد 390   ✓
  768  بدون تغییر          ✓
 1024  بدون تغییر          ✓
 1280  بدون تغییر          ✓
```

## ۲. فاصلهٔ ۶۲ پیکسلی پایین، حتی با نوار خاموش

```css
.hsw-pp { padding-bottom: calc(62px + env(safe-area-inset-bottom, 0px)); }
```

بدون هیچ شرطی. یعنی اگر نوار پایین خاموش بود، موبایل ۶۲px فضای خالی زیر مقاله داشت.

**رفع:** کلاس `hsw-pp--dock` فقط وقتی روی ریشه می‌نشیند که نوار واقعاً رندر شود، و قاعدهٔ فاصله به همان کلاس منتقل شد (هم در حالت موبایل، هم در `padding-bottom: 0` دسکتاپ).

**تأیید با جایگزینی واقعی استایل‌شیت روی صفحهٔ زنده:**

```
dock خاموش (بدون کلاس) : 0px
dock روشن  (با کلاس)   : 62px
```

## ۳. دکمهٔ «ثبت دیدگاه» بدون مقصد

در شاخهٔ «محصولی وجود ندارد»، دکمهٔ بزرگ نوار پایین همچنان بدون شرط به `#hsw-comments` لینک می‌داد. حالا همان گارد دکمهٔ «نظر» را دارد.

**تأیید با رندر مستقیم تابع:**

```
link_comments=true   → ۲ لینک #hsw-comments | دکمه رندر شد
link_comments=false  → ۰ لینک              | دکمه رندر نشد
```
