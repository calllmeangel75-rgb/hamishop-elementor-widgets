# HamiShop 1.11.209 - استایل دوم تب‌های محصول (بخش‌های زیرهم + نوار چسبان زیر هدر)

- **سبک دوم تب‌ها (`بخش‌های زیرهم + نوار چسبان زیر هدر`)**: قابل انتخاب در بخش «۸. تب‌ها (دسکتاپ و موبایل)» ویجت جامع صفحه کامل محصول و همچنین ویجت مستقل تب‌های محصول.
- **ترتیب نمایش زیر هم**: بررسی تخصصی کالا ← گارانتی و خدمات ← مشخصات فنی ← دیدگاه‌ها و نظرات خریداران.
- **نوار چسبان هوشمند (`data-hsw-tabs-scroll`)**: هنگام اسکرول به پایین، با حفظ فاصلهٔ مشخص و قابل تنظیم از هدر اصلی سایت چسبان می‌ماند و با اسکرول بین بخش‌ها، خط ظریف زیر عنوان بخش فعلی به‌طور خودکار جابه‌جا می‌شود (Scrollspy + اسکرول نرم با کلیک).
