# انتشار ۱.۱۱.۲۴۹ — بازبینی چهارم

تاریخ: ۲۰۲۶-۱۱-۰۶

---

## ۱. چهار ادعا، هر چهار بازتولید شد

| # | ادعا | حکم | قبل | بعد |
|---|---|---|---|---|
| ۱ | ذخیرهٔ پالت با فونت معتبر خطای رنگ می‌دهد | **درست** | `[error] … : font` + `[updated] ذخیره شد` | فقط `[updated]` |
| ۲ | `contrast_text('#777777')` زیر ۴٫۵ است | **درست** | `#111827` = ۳٫۹۶ | `#000000` = ۴٫۶۹ |
| ۳ | حالت‌های فونت به قانون عمومی پالت می‌بازند | **درست** | `Courier New` | `Vazirmatn HSW` / فونت قالب |
| ۴ | متن دکمه در hover سفید می‌شود | **درست** | `rgb(255,255,255)` روی `#f5f5f5` | `rgb(16,16,16)` |

---

## ۲. جزئیات

### ۲.۱ خطای فونت در ذخیرهٔ پالت

حلقه روی `defaults()` می‌گشت که `font` را هم دارد:

```
قبل : [error] این مقدارها رنگ معتبر نبودند و ذخیره نشدند؛ مقدار قبلی حفظ شد: font
       [updated] پالت رنگی ذخیره شد.
       saved primary=#123456 font=Vazirmatn HSW      ← فونت درست ذخیره می‌شد
بعد : [updated] پالت رنگی ذخیره شد.
```

حلقه به `tokens()` منتقل شد (فقط نقش‌های رنگی).

### ۲.۲ کنتراست

تابع نسبت **مشکی خالص** را حساب می‌کرد و بعد `#111827` برمی‌گرداند. ادعای «کف ۴٫۵۸» در یادداشت قبلی غلط بود.

```
#777777  قبل #111827 (۳٫۹۶)  بعد #000000 (۴٫۶۹)
#808080  قبل #111827 (۴٫۴۹)  بعد #000000 (۵٫۳۲)
#888888  قبل #111827 (۵٫۰۰)  بعد #000000 (۵٫۹۲)
```

حالا بهترینِ سه رنگی که واقعاً قابل بازگشت است انتخاب می‌شود.

### ۲.۳ ترتیب فونت

`.elementor-widget[…] :where(p, span, …)` هم (0,2,0) است — چون `:where()` وزن صفر دارد — و **بعدتر** بود، پس هر تساوی را می‌برد.

```
حالت design، <p> ساده   قبل Courier New (پالت)   بعد Vazirmatn HSW
حالت inherit، <p> ساده  قبل Courier New (پالت)   بعد -apple-system (قالب)
Typography المنتور     در هر دو غالب             Georgia
```

بلوک حالت‌ها بعد از قانون عمومی منتقل شد؛ Elementor (0,3,0) همچنان بالاتر است.

### ۲.۴ متن دکمه در hover

```
cta=#f5f5f5  cta_text=#101010
  عادی  : rgb(16,16,16)
  hover : قبل rgb(255,255,255)  →  بعد rgb(16,16,16)
```

قاعدهٔ hover به‌جای `--hsw-on-cta` مقدار `#fff` را سخت‌کد کرده بود.

## ۳. یک مورد که خودم اشتباه گفته بودم

در یادداشت ۱.۱۱.۲۴۸ نوشتم CTA سبد و تسویه کنترل رنگ اختصاصی ندارند. **داشتند**:

- cart-summary: `cta_bg` و `cta_tx`
- checkout-summary: `cta_bg` و `cta_c`

کنترل‌ها وجود داشتند، ولی حالت hover آن‌ها را نادیده می‌گرفت — دکمهٔ قرمز در hover آبی پالت می‌شد. هر دو کنترل حالا سایهٔ hover خود را از رنگ انتخابی می‌سازند و رنگ متن از طریق متغیر منتقل می‌شود.

## ۴. مواردی که هنوز باز است

**فوتر Woodmart.** پیشنهاد «محدود یا اختیاری» منطقی است ولی تصمیمش با مدیر است: اگر قاعده حذف شود، فوتر به ۴٫۲۳:۱ برمی‌گردد. راه‌حل پیشنهادی برای نسخهٔ بعد: یک فیلتر `hsw_archive_footer_contrast` که پیش‌فرض روشن باشد و با یک خط خاموش شود.

**توکن‌های success/danger.** بررسی اینکه کدام اجزا واقعاً به `--hsw-pal-success` / `--hsw-pal-danger` وصل‌اند انجام نشد؛ اتصال‌ها وجود دارند (`--hsw-pal-success-aa` و مشابه) ولی پوشش کامل اندازه‌گیری نشده.

**بارگذاری ویجت‌ها و CSS پالت.** اندازه‌گیری شد (۶۳ فایل، ۱٫۳۳MB، CSS ۱٬۴۶۹ بایت) ولی تغییری نداد — نیاز به پروفایل واقعی دارد.
