## ۲. تست‌های انجام‌شده

```
کیف پول خاموش (hsw_wallet_gateway_on = no)
  routes registered: topup=false  pay=false  convert=false
  فراخوانی مستقیم هندلر → 403
  points_convert_allowed → false

ارسال رایگان
  cost=0  label=«ارسال رایگان»  meta={"hsw_free_shipping":"1"}   (قبل: [])
  shipping transient version changed: true
```

## ۳. آنچه تست نشد

- **نشست واقعی مشتری** با نرخ کش‌شده و سپس خاموش‌کردن: منطق `get_transient_version` بررسی شد، ولی سناریوی مرورگری اجرا نشد.
- **پرداخت واقعی** و بازپرداخت.
- **چند روش ارسال و چند بسته**: فقط یک نرخ مصنوعی.

## ۴. تصمیم‌های باز

**تسویه و بازپرداخت بعد از خاموشی.** قطع‌کردن hookها وسط کار، مشتری‌ای را که پول داده بدون شارژ می‌گذارد. سیاست مکتوب لازم است.

**یکسان‌سازی روش‌ها.** همهٔ نرخ‌ها `method_id = free_shipping` و برچسب یکسان می‌گیرند؛ هر چیزی که به نوع روش برای مرسوله یا هزینه تکیه کند ممکن است متفاوت رفتار کند.

**سقف مناطق.** عدد پنل بیشینهٔ مناطق است، نه شرط مشتری فعلی.
