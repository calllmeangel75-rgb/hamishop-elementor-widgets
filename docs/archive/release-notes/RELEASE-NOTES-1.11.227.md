# یادداشت‌های انتشار نگارش 1.11.227 (Release Notes v1.11.227)

> **موضوع:** شیت «فیلتر پیشرفته» در موبایل باز می‌شد ولی **دیده نمی‌شد** — علت: ستون سایدبار با `display:none` مخفی شده بود و شیت داخل همان ستون بود.

## ۱. نشانه

- مرتب‌سازی کار می‌کرد.
- «فیلتر پیشرفته» هیچ چیزی نشان نمی‌داد — نه در سایت زنده، نه در `localhost/sks/shop/`.
- غیرفعال‌کردن LiteSpeed هم فرقی نداشت.

اینکه مرتب‌سازی کار می‌کرد ولی فیلتر نه، کلید ماجرا بود: هر دو از یک تابع و یک کلاس استفاده می‌کنند، پس مشکل در JS نبود — در **محل قرارگیری** آن‌ها بود.

## ۲. اندازه‌گیری واقعی (Chrome + CDP روی سایت لوکال، عرض ۳۹۰px)

قبل از رفع:

```
classes   : hsw-asheet hsw-asheet--filter hsw-m is-open
aria      : false
bodyLocked: true
display   : flex
visibility: visible
rect      : [0, 0, 0, 0]     ← عرض و ارتفاع صفر
```

یعنی شیت **باز می‌شد**، اما اندازه‌اش صفر بود. هیچ خطای JS هم نبود.

## ۳. علت

در `assets/css/hsw-composite.css`:

```css
@media (max-width: 767.98px) {
  .hsw-cp--archive .hsw-cp__body > .hsw-cp__col--side { display: none; }
}
```

این قاعده برای جلوگیری از یک layout-shift (۰٫۵۹۶۷ → ۰٫۱۵۸۱) اضافه شده بود: ستون سایدبار آرشیو در موبایل باید پنهان شود.

**ولی شیت پایین صفحه داخل همان ستون است.** ویجت فیلترها هم سایدبار دسکتاپ و هم شیت موبایل را در یک `<form>` رندر می‌کند و کل آن داخل `.hsw-cp__col--side` قرار می‌گیرد. با `display:none` روی ستون، شیت هم از صفحه حذف می‌شود — و چون `position: fixed` است، باز شدنش هیچ اثری ندارد.

شیت مرتب‌سازی داخل ویجت **نوار ابزار** است، بیرون از آن ستون — برای همین سالم بود.

## ۴. رفع

قاعده حالا به‌جای خود ستون، **باکس‌های دسکتاپ** را پنهان می‌کند:

```css
@media (max-width: 767.98px) {
  .hsw-cp--archive .hsw-cp__body > .hsw-cp__col--side .hsw-d { display: none; }
}
```

`.hsw-d` همان کلاسی است که سایدبار از قبل دارد (`.hsw-af__side`). نتیجه:

- سایدبار دسکتاپ در موبایل پنهان می‌ماند؛
- ستون به ارتفاع صفر می‌رسد (همان هدف CLS)؛
- شیت دیگر داخل هیچ `display:none` نیست و باز می‌شود.

همین انتخابگر در نسخهٔ inline داخل `HSW_Assets::print_layout_guard()` هم به‌روز شد (چون LiteSpeed با CSS Combine بلوک‌های inline را حذف می‌کند و آن کپی تنها نسخهٔ باقی‌مانده است).

## ۵. تأیید بعد از رفع (همان ابزار، همان صفحه)

```
sideColumn: { height: 0, width: 338, display: flex, asideHidden: true }
sheet     : rect [0, 0, 390, 844]  visibility: visible  opacity: 1
            transform: translateY(0)  onScreen: true
```

ستون هنوز ارتفاع صفر دارد (پس مشکل CLS برنگشته) و شیت تمام‌صفحه باز می‌شود.

## ۶. رابطه با ۱.۱۱.۲۲۶

۱.۱۱.۲۲۶ یک مشکل **دیگرِ واقعی** را رفع کرد: در `new.mrdastbaaf.com` اسکریپت‌ها با `type="litespeed/javascript"` چاپ می‌شدند و اولین تپ صرف دانلود باندل می‌شد. آن هم باید بماند.

ولی علتِ «هیچ چیزی بالا نمی‌آید» در سایت لوکال، همین ستون مخفی بود — و بدون این رفع، حتی با JS سالم هم شیت دیده نمی‌شد.
