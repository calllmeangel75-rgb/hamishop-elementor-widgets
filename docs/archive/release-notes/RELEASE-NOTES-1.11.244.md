# یادداشت‌های انتشار نگارش 1.11.244 (Release Notes v1.11.244)

> **موضوع:** ویجت تازهٔ «هدر GC» — همان طراحی نوار شناور با نشان مدار و پنل‌های کشویی، این بار به‌صورت یک ویجت بومی المنتور با کنترل‌های واقعی.

## ۱. از کجا آمد

فایل صادرشده از المنتور چهار ویجت HTML و یک اسکریپت پل ۳۰ کیلوبایتی بود: استایل‌ها در یک ویجت HTML، مارک‌آپ در ویجت دوم، منوی موبایل در سوم، و یک «پل» که مقادیر ویجت‌های کنترلی پنهان را با `MutationObserver` روی DOM اصلی کپی می‌کرد. زیبا بود، ولی هر تغییر کوچک یعنی ویرایش CSS داخل یک بلوک متنی.

این نسخه همان طراحی را به یک ویجت معمولی HamiShop منتقل می‌کند:

- نوار شناور با گوشهٔ گرد که با اسکرول به نوار تمام‌عرض مات می‌چسبد؛
- نشان برند به‌صورت «G» کشیده‌شده با خط مدار که هنگام ورود صفحه خودش را می‌کشد؛
- خط گرادیانتی زیر منو که با اشاره‌گر حرکت می‌کند و به صفحهٔ جاری برمی‌گردد؛
- پنل‌های کشویی که ردیف‌هایشان یکی‌یکی وارد می‌شوند.

## ۲. چه چیزی قابل ویرایش است

| بخش | کنترل |
|---|---|
| نشان | مدار GC / لوگوی سایت یا تصویر / آیکون مجموعه / بدون نشان |
| برند | نام فارسی، نام لاتین، لینک، اندازهٔ نشان |
| منو | پنج ردیف پیش‌فرض (عنوان + لینک + انتخاب پنل) |
| پنل‌ها | شش جایگاه؛ هر ردیف: آیکون، عنوان، توضیح، لینک |
| پایین پنل | ردیف نوع «لینک پایین پنل» به‌صورت لینک تأکیدشده |
| دکمه‌ها | سبد (با نشانگر تعداد)، حساب کاربری، منوی موبایل |
| رفتار | شناور یا درون جریان، آستانهٔ چسبیدن |
| رنگ | نُه کنترل رنگ، همه خالی‌به‌پیش‌فرض تا پالت حاکم بماند |

پنل‌ها با «جایگاه» آدرس می‌دهند، نه با شمارهٔ ردیف: ردیف منو «پنل ۲» را انتخاب می‌کند و ردیف‌های پنل هم «پنل ۲» را. بنابراین جابه‌جا کردن ردیف‌ها هیچ اتصالی را نمی‌شکند.

## ۳. قرارداد رنگ — با اندازه‌گیری تأیید شد

ترتیب مستند پروژه: کنترل ویجت > پالت > پیش‌فرض.

```
بدون پالت        →  trace = rgb(25,197,139)   CTA = rgb(6,39,31)
پالت بنفش        →  trace = پالت              CTA = پالت
کنترل دستی آبی   →  trace = کنترل             CTA = کنترل
```

هیچ کنترل رنگی `default` ندارد؛ دلیلش همان است که در ۱.۱۱.۲۲۱ نوشته شد — المنتور مقدار پیش‌فرض را در CSS صفحه چاپ می‌کند و پالت دیگر نمی‌رسد.

## ۴. دو باگ که در حین تست پیدا و رفع شد

### الف) دکمهٔ تیرهٔ کشوی موبایل، تیره روی تیره

```
قبل : color = rgb(23,43,37)  روی  bg = rgb(6,39,31)
بعد : color = rgb(255,255,255) روی  bg = rgb(6,39,31)
```

علت: `.hsw-gc a { color: inherit }` specificity (0,1,1) دارد و از `.hsw-gc__drawer-btn--dark` (0,1,0) قوی‌تر بود. همهٔ قواعدی که رنگ یک `<a>` را تعیین می‌کنند حالا پیشوند `.hsw-gc` دارند → (0,2,0).

### ب) سرریز افقی در موبایل

```
عرض    سرریز قبل   سرریز بعد
320    +172px       0
390    +102px       0
768       0         0
```

علت: `.hsw-gc__brand` مقدار `flex-shrink: 0` داشت؛ نام بلند فروشگاه به‌همراه سه دکمه در ۳۲۰px جا نمی‌شد و کل سند را کنار می‌کشید. حالا برند جمع می‌شود و متن با «…» کوتاه می‌شود، ولی نشان اندازهٔ خودش را نگه می‌دارد.

## ۶. کارهایی که انجام نشد (عمدی)

- **منوی وردپرس به‌عنوان منبع:** پنل‌های این طراحی آیکون و توضیح جدا برای هر ردیف می‌خواهند و منوی وردپرس این‌ها را ندارد. منبع، ردیف‌های خود ویجت است. اگر بعداً منوی وردپرس لازم شد، افزودنی است.
- **آیکون‌های خطی اصلی:** پنل‌ها از مجموعهٔ مشترک Material استفاده می‌کنند، نه آیکون‌های خطی طرح اصلی. دلیل: یک فهرست آیکون مشترک برای همهٔ ویجت‌ها (قاعدهٔ موجود پروژه).
