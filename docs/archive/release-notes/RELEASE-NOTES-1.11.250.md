# انتشار ۱.۱۱.۲۵۰ — تعارض specificity در hover سبد

تاریخ: ۲۰۲۶-۱۱-۰۶

---

## ۱. ادعا بازتولید شد

`.hsw-c .hsw-csummary__cta:hover` با (0,3,0) و بعدتر در فایل، قانون جدید `.hsw-csummary__cta:hover` با (0,2,0) را می‌شکست. هر صفحهٔ سبد داخل `.hsw-c` است، پس اصلاح قبلی در عمل هیچ اثری نداشت.

تست: صفحهٔ واقعی المنتور با ویجت «صفحه سبد خرید» و `csummary_cta_bg = #cc0000`، یک قلم در سبد، hover پالت `#1c3566`.

```
                  قبل (قانون قدیمی)        بعد
base              #cc0000                  #cc0000
hover             #1c3566 (آبی پالت)       srgb(0.688,0,0) ≈ #af0000
active            #0a1730 (پالت)           srgb(0.592,0,0) ≈ #970000
پایهٔ دکمهٔ موبایل  #0f2042 (پالت)           #cc0000
```

اثبات تعارض: با تزریق دوبارهٔ قانون قدیمی، hover به `rgb(28,53,102)` برگشت — همان آبی پالت.

## ۲. سه چیزی که همان تست بیرون کشید

**۱)** `:active` برای هر دو دکمه فقط از پالت می‌خواند. حالا هر کنترل سایهٔ active خودش را می‌سازد (`۷۴٪` رنگ انتخابی).

**۲)** پایهٔ دکمهٔ موبایل `var(--hswc-cta)` بود و متغیر خودش را نمی‌خواند. **این اشتباه فقط بین دو ویرایش همین نسخه وجود داشت:** در ۱.۱۱.۲۴۹ کنترل هنوز `background-color` می‌نوشت و درست کار می‌کرد. وقتی در ۲۵۰ به متغیر تغییرش دادم و پایه را به‌روز نکردم، رنگ بی‌اثر شد و در همان کامیت رفع شد — منتشر نشد.

**۳)** رنگ متن دکمهٔ موبایل هم به `--hsw-cs-mcta-tx` منتقل شد.

## ۳. دکمهٔ خالی سبد

`.hsw-c-empty__btn` کنترل رنگ ندارد؛ عمداً روی پالت ماند.

## ۴. اندازه‌گیری کامل — سبد و تسویه، دسکتاپ و موبایل

دو صفحهٔ واقعی المنتور (ویجت جامع سبد و ویجت جامع تسویه)، CSS تولیدشده، یک قلم در سبد، رنگ ویجت `#cc0000`، پالت `#0f2042` / `#1c3566` / `#0a1730`:

```
                 سبد دسکتاپ      سبد موبایل     تسویه دسکتاپ    تسویه موبایل
base             rgb(204,0,0)    rgb(204,0,0)   rgb(204,0,0)    rgb(204,0,0)
hover            srgb .688,0,0   srgb .688,0,0  srgb .688,0,0   srgb .688,0,0
focus-visible    srgb .688,0,0   —              srgb .688,0,0   —
active           srgb .592,0,0   srgb .592,0,0  srgb .592,0,0   srgb .592,0,0

با پاک‌کردن override
base             rgb(15,32,66)    —              rgb(15,32,66)   rgb(15,32,66)
hover            rgb(28,53,102)   —              rgb(28,53,102)  rgb(28,53,102)
active           —               —              —               rgb(10,23,48)
```

hover و active موبایل سبد با حذف overlay فوتر چسبانِ همان صفحهٔ تست اندازه‌گیری شد؛ روی صفحهٔ واقعی سبد، دکمه در مرکز خودش بالاترین عنصر است (`elementFromPoint`).

## ۵. پوشش‌نداده

- **حالت `focus-visible` روی دکمه‌های موبایل** اندازه‌گیری نشد.
- **کش صفحه/CDN** با رنگ‌های جدید تست نشد.

## ۵. موارد باز از قبل

- **فوتر Woodmart** — فیلتر اختیاری هنوز اضافه نشده.
- **توکن‌های success/danger** — پوشش اجزا اندازه‌گیری نشده.
- **هزینهٔ بارگذاری ویجت‌ها** — ۶۳ فایل، ۱٫۳۳MB؛ بدون پروفایل تغییر نکرد.
