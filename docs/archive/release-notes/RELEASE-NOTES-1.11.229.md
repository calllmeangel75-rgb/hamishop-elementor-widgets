## ۲. CLS — اندازه‌گیری واقعی

با PerformanceObserver روی همان صفحهٔ زنده، در عرض ۱۳۶۶px:

```
total: 0.2327 · count: 1 · time: 7900ms
sources:
  DIV.hsw-ahd__pills   y 298 → 297   height 33 → 74   ← رشد ۴۱px
  DIV.hsw-cp__body     y 396 → 436   height 504 → 464 ← جابه‌جایی ۴۰px
  NAV.hsw-hd__navmenu  width 590 → 594
```

**یک شیفت، در ثانیهٔ ۷.۹** — یعنی وقتی فونت قالب (YekanBakh) لود می‌شود. با فونت جایگزین، چیپ‌های زیردسته در یک خط جا می‌شوند؛ با فونت واقعی عریض‌تر می‌شوند و به خط دوم می‌روند. ردیف ۴۱px رشد می‌کند و هر چیزی که زیرش است ۴۰px پایین می‌رود. Chrome این را به `hsw-cp__body` نسبت می‌دهد چون آن جابه‌جا شده.

**رفع:** ردیف قرص‌ها دیگر wrap نمی‌شود؛ به‌جای آن افقی اسکرول می‌شود:

```css
.hsw-ahd__pills { flex-wrap: nowrap; overflow-x: auto; }
.hsw-ahd__pill  { flex: 0 0 auto; }
```

ارتفاع ردیف دیگر به فونت وابسته نیست، پس شیفت صفر می‌شود.

## ۳. ARIA

- **درخت دسته‌ها:** `<ul role="tree">` داشت ولی `<li>`ها هیچ نقشی نداشتند. حالا `role="treeitem"` + `aria-level` + `aria-expanded`. روی لوکال: ۳۸ مورد treeitem در صفحه.
- **کشوی موبایل:** وقتی بسته است `aria-hidden="true"` داشت ولی لینک‌هایش هنوز با Tab قابل دسترسی بودند. حالا `inert` می‌گیرد و با باز/بسته شدن، JS همان را toggle می‌کند. مرورگرهای قدیمی که `inert` را نمی‌شناسند، آن را نادیده می‌گیرند و کشو با CSS پنهان است.

## ۴. کنتراست — با اندازه‌گیری، نه حدس

روی صفحهٔ زندهٔ شما:

```
.hsw-hd__searchselect   #77716D روی #F8F4ED  →  4.39:1   (حد AA: 4.5)
.hsw-af__plabel         #77716D روی #F8F4ED  →  4.39:1
.hsw-agd__a             #77716D روی #F8F4ED  →  4.39:1
.hsw-ag__note           #0F9F6E روی #FFFFFF  →  3.38:1
```

سه مورد اول با رنگ «متن کم‌رنگ» پالت شما (`#77716D`) روی سطح کرم‌رنگ سایت رخ می‌دهد — **۰.۱۱ کمتر از حد**. مورد چهارم رنگ «موفقیت» پالت شماست که روی سفید خیلی روشن است.

**راه‌حل بدون دست‌زدن به انتخاب شما:** افزونه حالا یک نسخهٔ AA-safe از همان رنگ می‌سازد و فقط برای متن‌های کوچک استفاده می‌کند:

```php
HSW_Palette::readable_on( '#77716D', '#F8F4ED' )  // → #716b68
HSW_Palette::readable_on( '#0F9F6E', '#FFFFFF' )  // → #0d875e
```

رنگ‌هایی که از قبل قبول می‌شوند دست‌نخورده برمی‌گردند (`#047857` → همان). توکن‌های تازه: `--hsw-pal-muted-aa` و `--hsw-pal-success-aa`. رنگ پرکردنی‌ها (دکمه‌ها، بج‌ها، آیکون‌ها) عوض نشده‌اند.

## ۵. چیزهایی که رفع نشد و چرا

### چهار فایل CSS افزونه render-blocking هستند
`hsw-fonts` (۳.۸KB)، `hsw-header` (۹.۲KB)، `hsw-archive` (۷.۶KB)، `hsw-composite` (۰.۸KB) — جمعاً ۲۱KB.

این عمدی است: `HSW_Optimizer` آن‌ها را از ادغام LiteSpeed خارج می‌کند تا چیدمان و فونت به‌هم نریزد. ادغام‌شان در فایل ۵۵KB قالب، ۲۱KB را به مسیر بحرانی اضافه می‌کند ولی تعداد درخواست را کم می‌کند. اگر بخواهید، می‌توانم برای این چهار فایل `media="print" onload` بگذارم — ولی ریسک FOUC دارد و توصیه نمی‌کنم.

### تصاویر
`sizes` کارت‌ها `196px` است و تصویر نمایش‌داده‌شده ۱۷۶px — وردپرس نزدیک‌ترین سایز تولیدشده (۳۰۰px) را می‌دهد. برای صرفه‌جویی واقعی باید یک سایز تصویر ~۱۸۰px ثبت شود:

```php
add_image_size( 'hsw-card', 180, 180, true );
```
این کار تعداد فایل‌های تولیدی روی هاست را زیاد می‌کند؛ اگر بخواهید اضافه می‌کنم.

لوگو: `sizes="min(44px, 38vw)"` است ولی کوچک‌ترین سایز تولیدشده وردپرس ۱۵۰px است. برای ۲۶KB صرفه‌جویی باید سایز ۶۴px ساخته شود.

### فونت YekanBakh
۱۱۸KB و بخشی از مسیر بحرانی. مال قالب است. اگر قالب `font-display: swap` بدهد و فونت را preload کند، هم LCP بهتر می‌شود هم بخشی از شیفت‌ها. این را نمی‌توانم از داخل افزونه درست کنم.
