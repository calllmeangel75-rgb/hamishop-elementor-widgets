# یادداشت‌های انتشار نگارش 1.11.236 (Release Notes v1.11.236)

> **موضوع:** «لینک مرحله بعد» ویجت نادیده گرفته می‌شد + بازگرداندن مخزن به حالت سالم.

## ۱. وضعیت مخزن (مهم)

هنگام بررسی، دیدم پوشهٔ مخزن روی سیستم به یک **نسخهٔ قدیمی** برگشته بود:

```
27 فایل حذف‌شده  ← کل زیرسیستم تسویه/پرداخت/تکمیل
 6 فایل تغییرکرده
33 فایل، ۱۱٫۷۷۰ خط حذف
+ یک فایل ناشناس: includes/class-hsw-checkout-fields.php
```

یعنی `class-hsw-complete-route.php`، `class-hsw-widget-pay-page.php`، `class-hsw-widget-pay-methods.php` و بقیه **از دیسک پاک شده بودند**. هر بیلدی که از آن وضعیت ساخته می‌شد، صفحهٔ پرداخت و دکمهٔ تکمیل را نداشت.

**بستهٔ منتشرشده سالم بود** — بررسی کردم: `hamishop-elementor-widgets-1.11.235.zip` هر ۱۸۶ فایل را دارد، از جمله `pay-page`، `pay-methods` و `complete-route`.

مخزن با `git checkout -- .` به همان کامیت منتشرشده (`f5de077`) برگردانده شد. تنها چیز باقی‌مانده، فایل ناشناس `class-hsw-checkout-fields.php` است که هیچ‌جا require نمی‌شود.

## ۲. باگ واقعی این نسخه

در ۱.۱۱.۲۳۳ تصمیم «دکمه ناوبری کند یا سفارش بزند» فقط بر اساس «صفحهٔ پرداخت» گرفته می‌شد:

```php
'data-hsw-pay-step="' . ( $this->has_pay_step() ? '1' : '0' ) . '"'
```

اگر فروشگاه به‌جای «صفحهٔ پرداخت» از **«لینک مرحله بعد» روی همان ویجت** استفاده کرده باشد، آن لینک نادیده گرفته می‌شد و دکمه سفارش را ثبت می‌کرد — نه اینکه به صفحهٔ پرداخت برود.

### رفع

```php
$has_next_step = ! empty( $s['next_url']['url'] ) || $this->has_pay_step();
```

حالا اگر هر کدام تنظیم شده باشد، دکمه به همان مقصد می‌رود؛ فقط وقتی **هیچ‌کدام** نباشد سفارش را ثبت می‌کند.

## ۳. جریان سه‌مرحله‌ای که می‌خواهی

```
۱ سبد خرید
۲ تسویه (اطلاعات ارسال)
۳ صفحهٔ پرداخت: مشخصات تحویل + روش پرداخت + کد تخفیف + دکمهٔ تکمیل
۴ برگهٔ تشکر
```

مرحلهٔ ۳ همان «صفحهٔ پرداخت» است و باید یک **صفحهٔ جدا** باشد که این ویجت‌ها رویش هستند:

- «صفحه کامل پرداخت — حامی»
- «روش‌های پرداخت — حامی»
- «خلاصهٔ پرداخت — حامی»
- «کد تخفیف — حامی»

بعد در **حامی‌شاپ → تنظیمات → صفحهٔ پرداخت** همان صفحه را انتخاب کن. یا در ویجت «خلاصهٔ تسویه» فیلد «لینک مرحله بعد» را پر کن.

اگر آن فیلد خالی باشد و صفحه‌ای هم انتخاب نشده باشد، `data-hsw-pay-step="0"` می‌شود — همان چیزی که در `new.mrdastbaaf.com` دیدیم.
