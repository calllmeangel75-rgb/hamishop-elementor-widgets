# 1.11.271 — staging pre-release

Adds an administrator-only review queue for surviving media attachments referenced by tickets permanently deleted with this version active, including retention cleanup. Trash does not queue images. This is an inventory, not automatic deletion or proof of exclusive use. Previously deleted tickets and interruptions during cleanup may not be covered; media can be shared or public. Existing retention behavior is unchanged. Backups, email and external copies are unaffected. Not approved for production.
