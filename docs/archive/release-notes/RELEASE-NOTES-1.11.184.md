# HamiShop 1.11.184 — سازگاری با بهینه‌ساز لایت‌اسپید (LiteSpeed)

## چرا
روی سایت لایو، ساختار صفحه و فونت وقتی بهینه‌سازی CSS لایت‌اسپید روشن بود به
هم می‌ریخت و با خاموش‌کردنش درست می‌شد. دو مکانیزم مستقل پشت این است:

1. **ادغام CSS (Combine)** ترتیب کاسکید را عوض می‌کند؛ هر قاعده‌ای که فقط به‌خاطر
   «بعد از قالب لود شدن» برنده بوده، می‌بازد. ضمناً CSS المنتور
   (`elementor/css/post-<id>.css`) با هر ذخیره عوض می‌شود، پس فایل ترکیبی مدام
   بازتولید و کش‌ها بی‌اعتبار می‌شوند.
2. **UCSS / Critical CSS** فقط قاعده‌هایی را نگه می‌دارد که ژنراتور «در حال
   استفاده» دیده باشد. سبد کشویی، تب‌ها و آکاردئون در لحظهٔ تولید
   `display:none`اند، پس CSS آن‌ها حذف می‌شود و ویجت بدون استایل باز می‌شود.

## چه اضافه شد — `HSW_Optimizer`
از API مستند خودِ لایت‌اسپید استفاده می‌کند (نام کلیدهای تنظیمات از
`src/base.cls.php` همان افزونه خوانده شد):

| کلید/اکشن | کاربرد |
|---|---|
| `apply_filters('litespeed_conf', $slug)` | خواندن یک تنظیم |
| `do_action('litespeed_conf_force', $slug, $value)` | بازنویسی **فقط در حافظه** برای همان درخواست |
| `do_action('litespeed_purge_all')` | پاک‌کردن همهٔ کش‌هایش |
| `do_action('litespeed_disable_all', $reason)` | خاموش‌کردن برای همان درخواست |
| `optm-css_exc` / `optm-ucss_exc` | «CSS Excludes» و «UCSS excluded files» |
| `optm-css_font_display` | مقداری که روی همهٔ `@font-face`ها می‌نویسد |

- **خروج‌کردن CSS خودمان از ادغام و از UCSS:** خط
  `hamishop-elementor-widgets/assets/css` به `optm-css_exc` و `optm-ucss_exc`
  اضافه می‌شود — در حافظه، بدون نوشتن در دیتابیس، و **بدون دست‌زدن به خطوطی که
  خود صاحب فروشگاه نوشته**. اگر از قبل موجود باشد، دوباره اضافه نمی‌شود.
- **پاک‌سازی خودکار:** وقتی نسخهٔ افزونه عوض شود (همان نقطه‌ای که کش CSS المنتور
  هم پاک می‌شود) و وقتی پالت/تنظیمات حساب/تنظیمات امنیت ذخیره شوند،
  `litespeed_purge_all` اجرا می‌شود — پس بعد از آپدیت دیگر لازم نیست دستی کش را
  خالی کنی. برای WP Rocket / W3TC / SiteGround هم با تابع رسمی خودشان پاک می‌شود.
- **حالت ویرایش/پیش‌نمایش المنتور:** در `?elementor-preview` (و فریم‌های
  BeaverBuilder/Divi) بهینه‌ساز برای همان درخواست خاموش می‌شود، تا چیزی که
  ادیتور نشان می‌دهد همان چیزی باشد که ذخیره می‌شود.
- **اعلان در پیشخوان** (فقط صفحهٔ HamiShop، قابل بستن برای هر نسخه): وضعیت
  Combine/UCSS/Font-Display را نشان می‌دهد و توصیه می‌کند
  `elementor/css/post-` و `elementor/assets/css` را هم در CSS Excludes بگذارید؛
  اگر `Font Display` لایت‌اسپید روی `optional` یا `block` باشد هشدار می‌دهد،
  چون همان مقدار روی `@font-face` وزیرمتن هم نوشته می‌شود و فونت دوباره گاهی
  روی Tahoma می‌ماند.
- با فیلتر `hsw_optimizer_exclude` می‌توان خطوط خروجی را تغییر داد.

**هیچ‌چیز وقتی لایت‌اسپید نصب نیست اجرا می‌شود**: تشخیص با
`defined('LSCWP_CTRL') || has_filter('litespeed_conf')` انجام می‌شود و همهٔ
فراخوانی‌ها از طریق hook خودِ آن افزونه است (اگر ثبت‌نشده باشد، noop).

## نکته
این تغییر رفتار **پیش‌فرض امن** است: تنظیمات لایت‌اسپید شما را عوض نمی‌کند و
چیزی در دیتابیس نمی‌نویسد (جز یادداشتِ بستنِ اعلان). اگر بخواهید می‌توانید
خودتان هم `hamishop-elementor-widgets/assets/css` و
`elementor/css/post-` را در «CSS Excludes» بگذارید تا نتیجه قطعی‌تر شود.
