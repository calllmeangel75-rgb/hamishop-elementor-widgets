ویجت‌های لوپ محصولات و صفحه محصول ووکامرس برای المنتور — با شخصی‌سازی کامل فونت/رنگ/استایل، فونت وزیرمتن لوکال و عملکرد بهینه (Lighthouse 100).

== Description ==

تبدیل دقیق طرح HTML شما به ویجت المنتور، دسکتاپ و موبایل یکپارچه:

* **پیشنهاد شگفت‌انگیز**: گرادیان، تایمر شمارش معکوس، بنر شروع، نوار پیشرفت موجودی
* **پرفروش‌ترین‌ها**: نشان رتبه، دکمه خرید، منبع پرفروش‌ترین‌ها
* **محبوب‌ترین‌ها / منتخب**: تب‌های محبوب/جدید/بیشترین تخفیف، نشان ویژه/ارسال رایگان، حالت اتمام موجودی

== Single Product Widgets (جدید) ==

* همی‌راه محصول (Breadcrumb) — دسکتاپ و موبایل
* گالری محصول — بندانگشت دسکتاپ، دات موبایل، بج تخفیف و اصالت، بزرگنمایی
* نوار اعتماد و ضمانت‌ها — اصالت، ارسال فوری، بازگشت کالا
* عنوان، امتیاز و متا — عنوان فارسی/انگلیسی، کد کالا، امتیاز و وضعیت موجودی
* انتخاب رنگ و حافظه — موتور تنوع واقعی ووکامرس با سینک قیمت در همه ویجت‌ها
* ویژگی‌های شاخص — لیست تیک‌دار دسکتاپ / بنتو گرید موبایل
* جعبه خرید و قیمت — تعداد، AJAX افزودن به سبد، خرید فوری، گارانتی‌ها
* تب‌های محصول (دسکتاپ) — مشخصات، بررسی تخصصی، دیدگاه‌ها
* آکاردئون‌های محصول (موبایل) — مشخصات، دیدگاه‌ها، گارانتی و ارسال
* نوار خرید چسبان (موبایل) — قیمت، تعداد، افزودن به سبد با توست موفقیت

فونت وزیرمتن به‌صورت متغیر و لوکال داخل افزونه پک شده و در المنتور با نام «Vazirmatn HSW» قابل انتخاب است.

شخصی‌سازی کامل فونت، رنگ، استایل هر بخش + منابع مختلف محصولات (تخفیف‌دار، پرفروش، امتیاز، جدیدترین، دستی، دسته).

بهینه برای Lighthouse: بدون فریم‌ورک، آیکون‌های باندل‌شده (۲۵KB)، بارگذاری شرطی، بدون درخواست خارجی.

== Installation ==

1. پوشه افزونه را به ZIP تبدیل کنید.
2. پیشخوان → افزونه‌ها → افزودن → بارگذاری.
3. WooCommerce و Elementor باید فعال باشند.
4. در المنتور دسته «HamiShop — حامی» را انتخاب کنید.
