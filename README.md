# HamiShop Elementor Widgets

**ویجت‌های فروشگاهی سبک و بهینه ووکامرس برای المنتور** — ساخته‌شده با تمرکز روی سرعت، RTL و گرفتن نمره کامل **Lighthouse 100**.

> Lightweight & optimized WooCommerce widgets for Elementor — built for Persian/RTL shops and Lighthouse 100.

## ⚡ چرا لایت‌هاوس ۱۰۰؟

- **بارگذاری شرطی:** CSS/JS هر ویجت فقط وقتی لود می‌شود که واقعاً در صفحه باشد. صفحات بدون ویجت حامی = **صفر بایت** اضافه.
- **بدون jQuery، بدون فونت آیکون، بدون درخواست خارجی:** آیکون‌ها SVG اینلاین، ستاره‌ها متنی، بدون گوگل‌فونت و CDN.
- **JS فرانت ~۲.۳KB** مینیفای‌شده و `defer`.
- **بدون CLS:** همه تصاویر `width/height` و `loading="lazy"` دارند؛ تصویر اصلی محصول `fetchpriority="high"`.
- **انتخاب‌گر محصول AJAX:** ویرایشگر هرگز کل کاتالوگ را لود نمی‌کند.
- **استایل‌ها اینلاین از المنتور:** فایل‌های CSS ایستا فقط ساختاری هستند.
- **اعداد فارسی اختیاری** (قیمت‌ها ۰–۹) و حذف اختیاری CSS بلوک‌های ووکامرس.

## 🚀 نصب

1. پوشه `hamishop-elementor-widgets` را در `/wp-content/plugins/` قرار دهید (یا ZIP را آپلود کنید).
2. افزونه را فعال کنید.
3. پیش‌نیازها: **ووکامرس ۷+** و **المنتور ۳.۵+** (نسخه رایگان کافی است — نیازی به پرو نیست).
4. در المنتور، دسته **«حامی‌شاپ — ووکامرس»** را پیدا کنید.
5. تنظیمات تکمیلی: **تنظیمات ← حامی‌شاپ** (روشن/خاموش ویجت‌ها + عملکرد).

## 🧩 نکات استفاده

- **آرشیو:** حالت «آرشیو جاری» را در قالب‌های Product Archive المنتور (Theme Builder) استفاده کنید؛ «کوئری سفارشی» در هر صفحه‌ای کار می‌کند.
- **محصول تکی:** روی قالب Single Product المنتور حالت «محصول جاری»؛ برای پیش‌نمایش در ادیتور «انتخاب دستی».
- **سبد/پرداخت:** ویجت را جایگزین محتوای صفحه سبد خرید/پرداخت کنید (ووکامرس ← پیکربندی ← پیشرفته). مارک‌آپ بومی ووکامرس رندر می‌شود تا کوپن، AJAX و درگاه‌ها همیشه سالم باشند.
- **آیتم لوپ:** داخل Loop Grid المنتور حالت «محصول جاری حلقه» را بزنید؛ یا «انتخاب دستی» برای گرید محصولات منتخب.

