# HamiShop Elementor Widgets

[![CI](https://github.com/calllmeangel75-rgb/hamishop-elementor-widgets/actions/workflows/ci.yml/badge.svg)](https://github.com/calllmeangel75-rgb/hamishop-elementor-widgets/actions/workflows/ci.yml)

مجموعهٔ ۶۲ ویجت المنتور برای ساخت فروشگاه ووکامرس فارسی و راست‌به‌چپ — بدون کدنویسی، بدون فریم‌ورک، با پالت رنگی سراسری و بارگذاری شرطی دارایی‌ها.

ساختهٔ **HamiSys (حامی)** — [hamisys.ir](https://hamisys.ir/)

---

## این افزونه چه می‌کند

هر ویجت یک بخش واقعی از فروشگاه است، نه یک بلوک تزئینی: داده را از خود ووکامرس می‌خواند، با هندلرهای بومی کار می‌کند و در نبود ووکامرس یا المنتور خطا نمی‌دهد. می‌توانید صفحه‌ها را ویجت‌به‌ویجت بچینید، یا از ویجت‌های «صفحهٔ کامل» استفاده کنید و کل صفحه را با یک ویجت بگیرید.

## قابلیت‌های مشترک

- **پالت رنگی سراسری** — یک صفحه در پیشخوان، همهٔ رنگ‌های ویجت‌ها را تعیین می‌کند. کنترل رنگی هر ویجت، اگر تنظیم شود، بر پالت اولویت دارد.
- **فونت** — وزیرمتن متغیر و لوکال داخل افزونه؛ هر فونت دیگری از فهرست پالت یا با نوشتن نام دقیق خانواده قابل انتخاب است.
- **آیکون** — SVG درون‌صفحه (۱۰۱ نماد)، بدون فونت آیکون و بدون درخواست خارجی.
- **بارگذاری شرطی** — CSS و JS هر خانواده فقط در صفحه‌ای لود می‌شود که ویجتی از آن خانواده داشته باشد.
- **بدون وابستگی سنگین** — بدون jQuery، بدون Tailwind، بدون CDN. صفر درخواست خارجی.
- **فارسی و RTL** — ارقام فارسی، تاریخ شمسی اختیاری، چیدمان راست‌به‌چپ در همهٔ خانواده‌ها.

## نصب

نصب از **ZIP انتشار** انجام می‌شود، نه از سورس.

1. به صفحهٔ [Releases](https://github.com/calllmeangel75-rgb/hamishop-elementor-widgets/releases) بروید و فایل `hamishop-elementor-widgets-<version>.zip` آخرین نسخه را دانلود کنید.
2. پیشخوان وردپرس ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← همان ZIP را انتخاب و نصب کنید.
3. WooCommerce و Elementor را فعال کنید.
4. در المنتور، دستهٔ **حامی** را باز کنید.

> **از «Code → Download ZIP» استفاده نکنید.** آن فایل کل مخزن است (با `tests/`، `tools/` و `docs/`) و ساختار پوشهٔ نصبی وردپرس را ندارد؛ وردپرس آن را به‌عنوان افزونه نمی‌شناسد.

## شروع سریع

1. **HamiShop ← پالت رنگی** — رنگ اصلی، تاکید و فونت را یک‌بار تنظیم کنید.
2. **HamiShop ← کنترل ویجت‌ها** — اگر به بخش‌های مستقل نیاز دارید، روشنشان کنید.
3. یک صفحه بسازید و ویجت **صفحهٔ کامل محصول** (یا **صفحهٔ کامل سبد/تسویه**) را بکشید.
4. هدر و فوتر را در قالب المنتور (Theme Builder) با ویجت‌های هدر بچینید.
5. کش صفحه را یک‌بار پاک کنید.

## سازگاری

- **Hami Call for Price** — محصولات علامت‌خورده در همهٔ سطوح HamiShop متن و دکمهٔ تماس همان افزونه را نشان می‌دهند؛ هندلرهای ووکامرس تغییر نمی‌کنند.
- **افزونه‌های ورود پیامکی/OTP** — اگر افزونهٔ دیگری احراز هویت را در دست بگیرد، فرم ورود HamiShop کنار می‌رود.
- **HPOS ووکامرس** — سازگاری اعلام‌شده؛ همهٔ سفارش‌ها از `wc_get_order()` خوانده می‌شوند.
- **LiteSpeed و بهینه‌سازها** — دارایی‌های افزونه از ادغام و UCSS خارج می‌شوند تا چیدمان و فونت به‌هم نریزد.

## توسعه

```bash
php tools/ci-checks.php          # بررسی نسخه، دامنهٔ ترجمه، دارایی‌ها، کاتالوگ
php tests/harness.php            # لود همهٔ فایل‌ها به ترتیب وردپرس
python tools/build-assets.py     # بازسازی فایل‌های .min
python tools/build-release.py    # ساخت ZIP نصبی
```

جزئیات در [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md).
